Privacy Policy: WhatsApp Calendar Bot

Last updated: November 20, 2026

WhatsApp Calendar Bot ("the bot") is a private tool used by one household. It is not a public service, and it has no users besides the members of the household's WhatsApp groups.

What the bot accesses

  • WhatsApp: messages in the specific groups the bot was added to. It ignores all other chats.
  • Google Calendar: only the bot account's own calendar, through the calendar.events permission. The bot uses it to create and delete the events it books. It does not read or change any other person's calendar, and it does not access Gmail, Drive, contacts or any other Google data.

How the data is used

Group messages are analysed to detect agreed meetings and, in groups where the bot chats, to write its replies. The analysis is done by a language model that runs on the household's own computer. Messages are not sent to any third-party AI service.

Storage

Recent messages, pending proposals and records of created events are stored in a local database on that same computer, so the bot can follow a conversation and cancel its own events. Google sign-in tokens are stored on that computer and are never shared.

Sharing

Data is not sold, shared or transferred to anyone. Calendar invitations go only to a fixed list of household members' addresses set in the bot's configuration, never to addresses taken from chat messages.

Google API Services User Data Policy

The bot's use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the bot's local data folder removes everything it stored.
